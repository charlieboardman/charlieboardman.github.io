Cash Voucher Batch Printer

Static equivalent of print-vouchers.py. All vouchers are combined into a single multi-page document — one print command for the whole batch. Each page reproduces the cash-voucher6.html template exactly, with $FY/$NUMERAL substituted and @page{margin:0.25in;size:A4} applied (matching weasyprint's page geometry).
